PORTFOLIO — TRẦN THIÊN NGÂN
Sustainable Hospitality Six Senses Scholarship 2026–2027

CÁCH MỞ WEBSITE
1. Giải nén toàn bộ file ZIP vào một thư mục.
2. Mở index.html bằng trình duyệt Chrome, Edge, Safari hoặc Firefox.
3. Giữ các ảnh, PDF và XLSX trong cùng thư mục với index.html.

CÁCH ĐĂNG GITHUB PAGES
1. Tạo repository GitHub mới (hoặc dùng repository hiện có).
2. Upload index.html cùng toàn bộ các ảnh, file PDF và XLSX vào thư mục gốc repository.
3. Vào Settings > Pages, chọn Deploy from a branch, branch main, thư mục /(root).
4. Chờ GitHub Pages xuất bản địa chỉ công khai.

NỘI DUNG
- Có hai ngôn ngữ: tiếng Việt mặc định và tiếng Anh.
- Hai dự án nghiên cứu đều liên kết trực tiếp tới PDF và file Excel gốc.
- Contact sử dụng email và điện thoại của người ứng tuyển; website không có chức năng gửi form lên server.
- Trình duyệt có thể lưu tùy chọn ngôn ngữ trên thiết bị.
- Hiệu ứng cuộn mượt Lenis và font Onest sử dụng CDN; nếu ngoại tuyến, website vẫn hoạt động bằng cơ chế cuộn mặc định và font thay thế.
- Website là portfolio cá nhân, không phải website chính thức của Six Senses.
